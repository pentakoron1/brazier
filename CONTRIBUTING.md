# Here's how you can contribute to the project:

## Add Issues
- If you found a bug in the app, or something that you think would be better if it was changed.
- Even if you want to contribute to the code, please first create an issue so that others can know on what you are working.
- When creating an issue please first check that no one else has already created an issue about the same thing.
- Also check that you are on the latest version of the app, and that no one fixed the issue already.
- Be as precise as possible

**Those questions can help you write a good issue:**

**For bugs**
- Which device you are using?
- What can you do to reproduce the bug?

**For feature requests**
- The problem?
- Your proposed solution?
- Alternatives considered?
- You can include pictures or sketches to better describe your feature.
## Work on Issues
If you have some programming knowledge, feel free to directly contribute to the code. 

**Here's how you can do it:**
1) Clone the repository from GitHub.
2) Create a new branch: name it with the issue you're working on.
3) Make changes: Implement your solution.
4) Commit changes.
5) Push changes: upload changes to the remote repository.
6) Create a pull request: Reference the issue it addresses (e.g. Fixes #123).

I will then review and merge your changes into the main branch if they are valid.

**Tips**
- If it's your first time contributing, start small. The issues labeled with "good first issue" are a great way to get started.
- Consider commenting on issues before working on them so that you can share your implementation plan and I can then assign the issue to you. This is especially important if you are a new contributor or working on a big change.
## Translating the app

Even if don't have any programming knowledge, you can still help by translating the app. The languages we focus on for now are:

- English
- Spanish
- German
- French
- Hindi

But you can of course add another language if you want.

You are allowed to use AIs to help you translate text, but you still have to know the language you're translating to, so that you can review if the translations make sense or not.
